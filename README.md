# CX for PyMOL

CX 是一个将本机 Codex CLI 接入 PyMOL 的社区插件，可在停靠面板中对话、查看模型生成的代码并直接操作当前结构。它不是 OpenAI 或 PyMOL 的官方产品。

当前版本：0.7.0。当前安装脚本适用于 Windows；已在 Windows 的 PyMOL 3.1.8 Qt 图形界面验证。其他系统和版本尚未验证。

在 PyMOL 命令栏输入 `cx`，在主窗口左侧打开 CX 停靠面板；输入 `cx 你的问题` 可直接发送。菜单入口是 Plugin → CX · Codex 对话。可以拖动面板边缘调整宽度，关闭面板后再次输入 `cx` 可打开原对话。

## 使用

- 对话记录、图片附件和输入框位于同一块聊天区域；按 Enter 发送，Shift+Enter 换行。拖动回答区与输入区之间的横线可调整高度。“新对话”清空当前上下文。
- 使用顶部的“选择已有对话”下拉框切换 CX 对话；名称取自第一条问题。对话记录保存在本机 `work/cx/conversations/`，重启 PyMOL 后仍可选择，发送下一条消息时会尝试恢复 Codex 上下文。切换不会改变当前 PyMOL 结构，未发送的输入和附件留在输入区。0.7.0 之前的对话不会自动出现在列表中。
- 顶部模型下拉框从当前 Codex 配置动态读取可用模型。选择后点“新对话”，下一次发送时采用该模型；“默认模型”使用本机默认设置。当前对话固定使用建立时的模型，顶部状态显示实际模型和提供商。带图片时请选支持图片输入的模型。
- 图片可通过“图片”“粘贴”、在输入框 Ctrl+V 或拖入面板添加；“截图”附上 PyMOL 分子视图。双击附件移除。图片随下一条消息发送。
- Codex 可读取当前会话对象、链、配体及指定选区的原子坐标，每次最多 2000 个原子，并明确标记截断。
- Codex 生成的 Python/PML 自动执行，直接作用于当前打开的 PyMOL 会话。正在执行的任务会显示在状态栏。
- 每轮第一次执行代码前自动保存会话撤销点，最多保留最近 5 个；即使代码只读取结构也会保存。保存失败时不执行代码。点击“撤销”恢复到该轮执行之前；之后的手工会话修改也会被还原，可点击“恢复撤销前”找回撤销前的状态。撤销点仅在当前 PyMOL 进程中使用；切换会话文件后会拒绝恢复。
- 点击“运行记录”展开或折叠工具调用、代码、输出、错误和回合状态。记录保存在工作目录 `work/cx/`；Python 的普通 `print` 输出实时显示。
- 点击“停止”请求中断当前代码和 Codex 回合。Python 循环通常可以在下一次执行检查时停止，PML 在命令之间停止。底层原生计算或阻塞调用如果本身不能中断，需要等该调用返回；极少数长时间占用 Python 的全局解释器锁的调用也可能使界面暂时无响应。已经完成的操作不会自动撤销。关闭面板仅隐藏；输入 `cx` 可重开。

## 示例

```text
cx 先检查当前对象、链和配体，告诉我可分析哪些结构
cx 列出配体周围4埃内的残基，并输出最短重原子距离
cx 将当前结构显示为蓝色卡通，配体显示为黄色棒状
```

PyMOL 原命令栏里的分号仍可能被它自身解释为命令分隔符；复杂文本和多行问题请在 CX 面板输入。

## 环境与安装

需要 Windows、PyMOL Qt GUI、PowerShell，以及已安装、登录或配置并可实际推理的 Codex CLI。沿用本机 Codex 登录和提供商设置；模型可在面板中为新对话选择。插件没有单独的 API 密钥。

下载并解压本仓库文件，在该目录打开 PowerShell，执行：

```powershell
.\install_cx.ps1
```

安装到默认 PyMOL 目录后重启 PyMOL，在命令栏输入 `cx`。如果 PyMOL 装在其他位置，可运行 `.\install_cx.ps1 -PyMolRoot "D:\你的PyMOL目录"`。执行 `.\install_cx.ps1 -Uninstall` 卸载本插件。安装器不会更改 Codex 配置或已有结构文件。安装复制了插件代码；修改源代码后需重新安装。

自动寻找 npm 安装中的 `codex.exe`，也可用环境变量 `CX_CODEX_EXE` 指定绝对路径。

## 使用边界

结构摘要、请求的坐标、附件图片和代码输出会按现有 Codex 提供商配置发送；请只处理允许发送给该服务的数据。

自动执行的 Python/PML 具有 PyMOL 进程的权限。执行中发生错误或按停止后，之前的操作可能已经生效。插件保留代码、输出和错误供查看，不承诺自动撤销。

撤销只恢复 PyMOL 会话，不能撤销代码对外部文件或其他程序的操作。会话文件名相同并不保证仍是同一工作内容，切换或重建无文件名的会话时请格外留意。

新版插件为每个 PyMOL 进程建立私有临时目录，正常退出时清理自己的截图、剪贴板图片和撤销点；异常退出、仍有代码运行或恢复失败时可能保留以便恢复。运行中最多保留 20 张生成的临时图片；待发送和发送中的图片受保护，可能暂时超过上限。用户选择的图片原件不会删除。

新版运行日志保存在 `work/cx/audit/`，每个日志文件约 5 MiB，最多保留 3 个轮转文件。插件启动时清理旧日志，保留最近 10 组已结束进程的日志，运行中的进程日志额外保留。旧版 `work/cx/session_*.log` 和旧版图片不受自动清理。日志可能包含代码及输出，请妥善保管。

距离、图片及结构预测不能单独证明氢键、亲和力或生物学机制。模型是否支持图片以实际调用结果为准。

使用 Codex app-server 的实验性动态工具接口；未来 CLI 升级如改变接口，可能需要更新插件。
